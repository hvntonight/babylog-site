使用帮助

记录、提醒、备份，遇到问题从这里找。

请说明 App 版本、设备型号、系统版本和操作步骤。截图请遮挡宝宝姓名与敏感内容，不要发送完整照护历史、密码或身份证明。

如何开始记录？

添加宝宝姓名和生日后，在“今天”选择常用记录，或点“更多记录”。记录可以补填时间、编辑和删除。多个宝宝可在档案处切换。

备份后可以恢复什么？

JSON 备份包含全部宝宝、记录、提醒和设置，支持新版和旧版 BabyLog JSON。导入前会展示预览；请确认文件来源。CSV 是明细表，不是可恢复的完整备份。

换机或卸载前要做什么？

在“宝宝 → 数据与备份”导出 JSON，保存到你能够再次访问的位置，并确认文件存在。卸载或丢失设备后，没有备份的数据无法恢复。导出文件没有 App 额外加密，请妥善保管。

为什么没有收到提醒？

照护间隔提醒默认关闭。先设置间隔并启用对应提醒，再允许系统通知。检查系统通知权限、专注模式和通知预览。提醒是本机安排，不是持续监护或健康警报。

亲喂计时如何使用？

选择“喂奶 → 亲喂”，开始后可切换左右侧、暂停和继续，结束后保存实际时长。离开页面不会丢失已保存的计时状态；它不是系统实时活动或后台录音。

能和家人自动同步吗？

当前版本没有账号或多人云同步。你可以主动导出文字交接、CSV 或 JSON，通过系统分享面板交给家人。分享是文件副本，不会自动合并后续记录。

历史预测和补剂用量可信吗？

历史区间依据你输入的有效日志在本机计算，不会识别宝宝是否饥饿。没有记录不代表没有照护。补剂只记录实际使用情况，不建议用量。健康问题请联系专业人员，不要等待提醒。

应用内也可在“宝宝 → 隐私政策”离线查看完整政策。
